# 한모 학업 코어 · 학생용 UI

한모의 학생용 화면은 모두 저장소 루트 **`html/`** 폴더에서 제공됩니다. `js/academic/`은 TypeScript 학업 계산 코어와 단위 테스트, `data/`는 학사자료, `scripts/`는 검증·배포 빌드 스크립트를 담는 폴더이며 공개 웹사이트에서 `/degree-rescue/` URL을 제공하지 않습니다.

학생용 기능 바로가기: [학업 플래너](../html/planner.html) · [학사 공지](../html/academic-timeline.html) · [개설 전망](../html/forecast.html) · [강의 검색 안내](../html/catalog.html) · [학점 정리](../html/academic-progress.html) · [가상 돌발상황 설정(기본 OFF)](../html/vsugang.html#scenario-settings).

## 학생용 UX 계약

- 직접 작성한 JSON, WIS 페이지 HTML 저장·업로드, 개발용 근거 원장 입력을 **학생에게 요구하지 않습니다**. 데이터 미연결 상태는 정직하게 보류하고 학교 공식 확인 경로를 제공합니다.
- **강의 전망**은 학수번호·학기 입력 폼과 TypeScript 코어의 `UNKNOWN` 판정을 사용합니다. #95에서 합성 개설 관측·예시 버튼을 제거했으며, 승인 자료가 없으면 개설 여부를 확정하지 않습니다.
- **강의 검색**은 `academic-data-source.js`의 승인 공개 읽기 경로를 사용합니다. 기본 연결 설정은 비활성이고 결과는 비어 있으며, 합성 강좌 미리보기는 #95에서 제거했습니다.
- **학사 공지**는 과거 제목 참고 JSON을 #95에서 제거했습니다. 현재 공개 설정이 비활성화되어 있으며 학생 대상·신청 마감 개인화/D-day는 확정하지 않습니다.
- **NLP 선행 코어(2026-11-21):** #97 근거 문단 인덱스, #98 평가 분할·지표 계산, #99 공지 대상·기한 후보 추출을 `js/academic/core/campus-assist/`에 병합했습니다. **합성 테스트를 통과한 순수 코어이며 실제 학교 자료/학생 화면에는 아직 미연결**입니다. 독립 검수와 운영 인수는 [아키텍처 §4.4·§4.6](architecture.md)를 따릅니다.
- **학점 메모**는 사용자가 입력한 숫자의 단순 합계이며 교육과정·재수강·이수구분 판정이 아닙니다. 입력된 학점은 자동 저장하거나 전송하지 않습니다.
- 사이트의 내비게이션은 상단 가로 메뉴입니다. 좌측 사이드바를 두지 않습니다. **PC 전용 접근 정책**은 유지합니다.
- **`html/practice.html`, `html/selectZone.html` 및 해당 원본 동작은 변경하지 않습니다.** 기본 모의신청에 새 시나리오를 임의로 연결하지 않습니다.

## 개발·검증

```bash
npm install --ignore-scripts --no-audit --no-fund
npm run check
```

검사는 TypeScript 타입 검사, 기존 합성 모델 회귀 테스트, 학생용 번들 생성, `html/` 링크/접근성/PC 정책, 비개발자 입력 보안 및 GitHub Pages 정적 번들을 확인합니다. 산출물은 `dist/`이며 폴더명은 **빌드 결과 디렉터리**일 뿐 학생 방문 URL은 아닙니다. `dist/CNAME`은 만들지 않습니다.

학교 자료 사용권 및 출처 확인은 [#27](https://github.com/ot4562-glitch/Hanmo_develop/issues/27) 회신 전까지 보류하며, 공식 학적·강의·접수일을 임의 확정하지 않습니다. PR 병합 및 운영 사이트 배포는 별도 승인 대상입니다.
