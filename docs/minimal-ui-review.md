## 범위와 판단 기준

2026-11-23 요청에 따라 기준 커밋 `0df1c0dafd23939f48b35aa68614e8461bb83b31`의 HTML 14개와 연결된 스타일·스크립트를 검토하고, 공개 배포 사이트의 모든 경로를 실제로 방문했습니다. 기준은 [100가지 슬롭·100가지 비슬롭 문서](ai-slop-vs-intentional-design-200-signals.md)입니다. 이 목록은 미감 점수나 인증 기준으로 사용하지 않습니다.

## 오픈소스

- **FullCalendar Standard 7.1.5 (MIT)**: 기존 설치 버전을 유지합니다. 달력·월 이동·키보드 접근을 새로 구현하지 않고 공개 역할/날짜 속성과 `dayCellTopClass`·`dayHeaderInnerClass` 옵션으로 간격을 조정합니다. [공식 라이선스](https://fullcalendar.io/license)
- **Lucide Static 1.78.0 (ISC, Feather 유래 일부 MIT)**: npm의 고정 버전에서 `search`, `external-link`, `rotate-ccw`, `arrow-right` SVG 원본 네 개만 가져왔습니다. 합계 **1,489바이트**이며 런타임 JS·외부 CDN 요청을 추가하지 않습니다. 원본 [전체 라이선스](../img/lucide/LICENSE)를 함께 배포합니다. [공식 라이선스](https://lucide.dev/license)
- **Playwright 1.65.1**: 기존 버전으로 실제 동작·화면 크기·상태를 검증합니다. 학교 자료 대신 합성 응답을 사용합니다.

아이콘은 텍스트 레이블을 유지한 동작에만 사용하며 `aria-hidden`으로 중복 읽기를 막습니다. 장식용 아이콘·새 UI 프레임워크·새 폰트 다운로드를 추가하지 않습니다.

## 보호와 증거

`hanmo-refined.css`는 검토한 화면에서만 마지막에 로드합니다. 보호 대상 두 페이지는 이 스타일을 불러오지 않습니다. 두 페이지의 HTML, 신청/타이머 JS, normalize/gnb/practice/고지 공통 CSS, 공유 이미지·진입 스크립트는 기준 커밋과 바이트 단위로 비교합니다. UI manifest는 승인된 변경 파일만 갱신하며 그 자체를 시각 검증 완료로 간주하지 않습니다.

새 `e2e/refined-ui.spec.mjs`의 31개 검사는 키보드 진입, 미연결·오류·빈 자료·검증 실패·검색 결과 없음, 달력 이동과 1280×720·1440×900·1920×1080·960×540 화면을 다룹니다. 기준 커밋을 별도 임시 경로에 빌드해 1440×900 전후와 1280×720 변경 화면을 기록합니다. 날짜·난수·합성 저장값을 고정하고 외부 요청을 차단합니다. 스크린샷에는 실제 사용자·학교 자료가 없습니다.
